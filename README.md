# 🏛️ KolKatha - AI Heritage Guide

**KolKatha** is an AI-powered heritage guide for the City of Joy, Kolkata. It acts as a witty, nostalgic local friend who tells you stories, facts, and food recommendations.

![Kolkata Banner](1.jpg)

## ✨ Features
* **🎭 Local Persona:** Speaks with the warmth and nostalgia of a true Kolkata resident.
* **📸 Multimodal Chat:** Upload images of monuments to get instant history and facts.
* **💾 Smart History:** Chat history is saved automatically using **Firebase**.
* **🎨 Dynamic UI:** Dark Mode interface with "Typewriter" effects and Gold/Sunset colors.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JS, Firebase (Auth & Firestore)
* **Backend:** Node.js, Express, Google Gemini AI
* **AI Model:** `gemini-1.5-flash` (Stable & Fast)

## 🚀 How to Run
1. Clone the repo.
2. Run `npm install`.
3. Create a `.env` file with `GEMINI_API_KEY=your_key`.
4. Run `npm start`.
